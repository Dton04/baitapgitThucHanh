## 🛠 Quy trình Git bắt buộc
1. Không push trực tiếp lên `main` và `develop`.
2. Mọi tính năng thực hiện trên nhánh `feature/*`.
3. Tạo **Pull Request** và chờ Lead duyệt trước khi merge vào `develop`.
